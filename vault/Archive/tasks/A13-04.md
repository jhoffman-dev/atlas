`isVisibleEntry({ kind: 'file', name: 'deleted.md', path: '.trash/deleted.md' })` is true. Same for `.git/COMMIT_EDITMSG`, `.obsidian/workspace.md`, and `.atlas/views/Board.md` — which would put a Board in user space as well as in Views.

The tree never sees it because it walks lazily and stops at the hidden folder. But `listVaultNotes` filters a **flat** list with this rule and nothing else, so on the domain's own rule a deleted note is a wiki-link target. It is masked only because Rust's `collect_notes` skips dotted directories first — **which is exactly the duplicated rule ADR-0005 and CLAUDE.md say must not be relied on, and Rust's copy is the stricter one.**

Either the rule looks at ancestors, or its doc comment is wrong and says the caller owns them. One of the two has to move.
