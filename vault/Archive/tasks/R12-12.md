`RELATIVE_DATES[value] ?? null` reads the prototype chain, so a view filtering `title contains "constructor"` compiles to `WHERE "title" LIKE '%' || function Object() { [native code] } || '%'` with the value never bound. `__proto__`, `toString`, `valueOf` and `hasOwnProperty` do the same. This breaks the module's own stated invariant that values are always bound, and it is reachable from any saved view whose filter text happens to be one of those words.
