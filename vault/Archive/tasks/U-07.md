James, 2026-09-23: "This is looking great the UI is beautiful now. However we have a lot of work to do on the functionality:

1. I can create new dashboards but I can't add, edit, remove, move, resize, widgets. I also need to be able to remove dashboards.
2. I don't see a way to create new types. This was one of my original requirements. I want to add custom types that I can define the properties and relations between types. I also want to be able to run queries (sql style preferred) and save the queries into views and / or dashboards.
3. I need to be able to create new folders in the pages section and notes inside of them.
4. I need to be able to delete notes and move notes.
5. I need to be able to link notes. I would also love to have a graph view or flow chart to see connections and relationships between notes.
6. Another default type that I need is projects and tasks should have a projects relation so they can be filter and / or grouped by projects.
7. I would like to have custom views that can be saved. Also more view types like, card view (gallery view), feed view, and list view.
8. The tasks view I would like to have checkboxes that if clicked automatically move the task to a done status.
9. I need a way to edit the types. For example, I want to change the status options for tasks.
   Always let me know if I need to restart the app to view changes."
