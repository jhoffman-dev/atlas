`{ paths: new Array(2), focused: 1 }` gives an array with holes: `Array.map` preserves them, so `paths[1]` is undefined while the type says `VaultPath | null`, breaking the invariant that `focused` names a pane that exists. `openInFocused` then maps over the same holes and skips them, so every later open is silently dropped and the window never changes.

Not reachable through `JSON.parse`, which has no holes — reachable through any other store handed to the port, and the parameter is typed `unknown`, which invites one.
