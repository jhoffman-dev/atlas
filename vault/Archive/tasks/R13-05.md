The refusal machinery is correct — `saveNote` always passes the modification time, `setNoteProperties` re-reads first, and both the Rust host and the e2e fake enforce it. But nothing in `packages/`, `apps/` or `e2e/` exercises a write to a note that is open. `e2e/watcher.spec.ts` looks like it does and writes a different file.

The highest-risk behaviour in the phase is unasserted, in either direction.
