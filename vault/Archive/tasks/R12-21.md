`SOURCE_PATH_KEY` is `source`, and `.atlas/types/task.md` already declares `source: text` for the `source: you` convention on the board. Harmless today — a note belongs to a source only when `source` equals that source note's path — but it is a live collision in the one vault we dogfood in, and it would be worse the moment someone maps a field onto it. Either namespace the key (`atlas_source`) or rename the board's convention.
