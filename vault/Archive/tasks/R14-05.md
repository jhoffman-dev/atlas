`take()` in `stranded-edits.ts` removes the stored entry the moment a pane opens the note. If the file changed on disk, the pane then shows "Overwrite or Discard?" — and the only copy of the work is React state. Quit or crash while that prompt is up and the work is gone for good, which breaks the one promise R13-11 made. No unload handler exists to save it.

Keep the entry until the work is written or discarded: `take` peeks, and the entry is forgotten on a successful save or on Discard. e2e: reopen, restart **before choosing**, the work is still offered.
