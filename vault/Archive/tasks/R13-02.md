Note open in both panes; type in pane 2; star it from pane 1. Pane 2's autosave is correctly refused — that part works as designed. But there is no way out: the autosave effect only re-runs on a keystroke, there is no reload-and-lose or overwrite affordance, and closing the pane runs the unmount save, which is refused too and swallowed by an empty catch.

`apps/desktop/src/notes/use-note.ts:158-172`. At minimum the unmount path must not drop the work silently; better is a choice between discarding and overwriting.
