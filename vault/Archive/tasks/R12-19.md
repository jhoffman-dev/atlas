`missingProperties()` writes `source_missing: true`, but nothing ever clears it — there is no inverse. A note whose record returns to the feed keeps the mark for good, and every view filtering on it goes on hiding the note. Deciding what a refresh writes is the domain's job, so the fix belongs in `planRefresh`, not in the application layer.
