`createVaultPath` splits on `/` only, so `..\\..\\secrets.md` survives as a vault path. Harmless on macOS, where it is merely an odd filename, and Rust re-checks after canonicalising — but it is the one input in this area that is not rejected, and the project is not macOS-only by design.
