Found by both Phase 14 passes independently.

1. When `put` fails (quota, private window) the work lives only in `kept.current`, and the notice warns it is lost _if Atlas quits_. Switching A → B → A runs the load effect, which resets `kept.current = new Map()` — lost without a quit.
2. When work for a vault that is no longer open is kept (the R14-01 path: a flush refused during the switch) and `put` fails, the early `if (vault !== vaultKey) return;` skips both the in-memory copy and the notice. Silent loss.

Keep unstored work in memory keyed by vault, not only for the open one, and raise a notice when a put fails for any vault. Tests: `apps/desktop/src/notes/stranded-edits.vault-switch.test.ts` (2 failing).
