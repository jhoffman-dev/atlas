Two record keys that sanitise to the same filename collide: `Foo Bar` and `Foo/Bar` both give `imported/Foo-Bar.md`, while the plan dedupes on the raw key. A hand-written `projects/Roadmap.md` plus a record keyed `Roadmap` with `into: projects` plans a `create` straight over it — and the same plan can emit `create` and `missing` for one path.

The computed path has to be the identity: dedupe on it, suffix collisions, and never plan a `create` for a path an existing note already holds.
