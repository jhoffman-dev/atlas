`playwright.config.ts` pins port 4173, and agents work in git worktrees that all
share it. `reuseExistingServer: false` stopped a run silently testing another
worktree's build, which was the worse failure — but it did not stop the
contention. A full suite run against a contended port took **7 minutes 48
seconds and failed six tests**; the same tree ran clean in 16 seconds once the
other server was gone.

Seven minutes of red that the code did not cause is worse than a fast honest
failure, and it has now cost time twice.

Give each checkout its own port — derive it from the working directory, or take
it from an environment variable the worktree sets — so two suites can run at
once without either knowing about the other.
