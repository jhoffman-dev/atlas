`packages/application/src/api/`: `routeApiRequest(request, deps) → ApiResponse` for every route in `API_ROUTES`, built on the existing use-cases. Pure; tested with fake ports.

- Path validation: percent-decoded, vault-relative, no `..`, no absolute, nothing under `.atlas` → `invalid`.
- Body validation per route → `invalid` with a message naming the field.
- `ifModified` → `conflict`; `PUT body` without it → `invalid`.
- Open-pane routing is a port (`OpenNotes`): property writes go through the pane; body writes to a dirty pane → `unsaved_in_app`; to a clean pane → write then reload it.
- No vault → `no_vault` on everything but `/v1/status`.
- Unknown route → `not_found_route`; thrown errors → `internal`, never a leaked stack.
