Swap the hand-rolled arc and line maths for `d3-shape` and `d3-scale` — geometry only. Atlas goes on rendering its own SVG so the flat-fill look survives.

Phase 13 put that maths behind a seam in `packages/ui/src/charts/` precisely so this is a contained change. If it turns out not to be contained, that is a finding about the seam worth writing down.

Measured on landing: **+29 kB raw, +11.7 kB gzipped**, not the ~10 kB this card
guessed. The cost is not `d3-shape`, which is small — it is `scaleLinear`,
which pulls `d3-interpolate`, `d3-color` and `d3-format` behind it via
`tickFormat`. The import surface is already five named imports and the unused
scales did tree-shake out; trimming further would mean reaching into
`d3-scale/src/`, which is not a public entry point and is not worth it.
