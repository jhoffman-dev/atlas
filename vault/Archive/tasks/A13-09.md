`collect_notes` (`apps/desktop/src-tauri/src/vault.rs:405`) skips every dotted
directory before the list crosses IPC, so `.atlas` notes never reach
`list_notes` at all and are not wiki-link targets.

That is Rust deciding, which ADR-0005 says it must not do — and now that
`isVisibleEntry` inspects ancestors properly, Rust's copy is the **only**
remaining one. While the TypeScript rule was the weaker of the two, Rust was
quietly keeping us safe; now it is quietly making a different decision, and the
two can drift without anything noticing.

The fix is Rust returning everything and TypeScript filtering. That changes
`list_notes` semantics — `.atlas` notes would become wiki-link targets and
would reach the index — so it needs its own e2e pass and a think about whether
that is wanted. It is not a one-line change, which is why it is a card rather
than a footnote.
