`compareNames` uses collator sensitivity 'base', so `Notes.md` and `notes.md` (or `Resume.md` and `Résumé.md`) tie on title _and_ on the path tiebreak. The sort is stable, so the two come back in whatever order they arrived — and the two sources are a SQL result and a directory walk, so the order can change between refreshes with nothing changed on disk. Rows move under the pointer.
