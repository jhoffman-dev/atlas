`apps/desktop/src-tauri/src/api.rs`. Decides nothing (ADR-0005): authenticates and forwards.

- Bind `127.0.0.1` only; reuse the port from the connection file if free, else let the OS choose, and rewrite the file.
- Bearer token, constant-time compare → 401. `Host` not `127.0.0.1:<port>`/`localhost:<port>` → 403. Any `Origin` → 403. Body > 1 MiB → 413, refused before it is read.
- Forward as `ApiRequest` on the `api-request` event; answer from the `api_respond` command; 30 s → 504.
- Connection file `api.json` in the app data dir, mode 0600, never in the vault. Commands: enable/disable, status, rotate token.
- Tests for every refusal, round-trip and timeout.
