`niceTicks({ max: Number.MIN_VALUE })` underflows: the magnitude is 0, so the step is 0, and the loop pushes a tick every pass without ever advancing. Heap death in about 150ms under a 64MB limit; otherwise the window simply freezes. `count: Infinity` does the same — `Math.max(count, 1)` guards zero and negatives but not the non-finite.

Unreachable from note counts today, but the failure mode is a frozen app and the guard is one line. The test runs it in a child process on purpose: in-process it would hang the suite rather than fail it.
