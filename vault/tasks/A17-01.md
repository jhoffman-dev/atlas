Adversarial pass on P17-07; failing tests in commit c9e02e3 (branch worktree-agent-ab322418bf170b16a).

1. **High.** `withArtifactCsp` finds `<head>` by regex; a commented `<head>`, `<head>` in an attribute, in `<noscript>`, a script before the head, or content before a late head puts the CSP where WebKit ignores it — the page loads from anywhere (confirmed in WebKit).
2. **High.** `<meta http-equiv=refresh>` navigates the frame to any site, which then runs in Atlas's pane with no CSP (exfiltration, phishing). No CSP directive blocks it — refuse sub-frame navigation in the host, or reset the frame on a second load.
3. Medium: two titles with the same slug share a copy folder (one artifact injects `app.js` into the other). Medium: long titles exceed 255 bytes and leave an orphan copy folder.
4. Low: API chunks skip the 200-file cap; `saved:` can point at a notes folder; Pages hides a note folder whose name matches any note in `artifacts/`; a link dragged in from a browser may navigate the app (needs the real app).
