Failing tests on branch `worktree-agent-a525958e375fcf0ed` (commit 3390a7a); review findings from the code-reviewer pass.

**High:**

- **Dropped in tables:** a bookmark in a table cell is dropped on save, so the link is lost.
- **Nested cards:** the editor lets a card into quotes, callouts, table cells and list items (drag and paste). Keep cards top-level: lift or refuse them, as ADR says.
- **Paste loses the target:** copy and paste of a bookmark loses target, heading and alias. A pasted inline `[[link]]` has the same pre-existing gap; fix both with parseHTML attrs.

**Medium:**

- **Nested bookmarks don't read back:** a nested bookmark saves and reads back as a raw block (moot once nesting is impossible, but keep the test).
- **Emphasis in names:** targets with emphasis characters (`_draft_`, `a*b*c`, `~~x~~`, `a<b>`) read back as raw — match the block's source line rather than the mdast shape. The inline `[[_draft_]]` reading as italic is pre-existing; fix it if the same change covers it.
- **Reload on every save:** cards re-read on every save in the vault, including the note's own autosave, and each re-read leaks a blob URL. Reload only cards whose target changed, cache the picture URL per (path, src), and revoke old ones.

**Low:**

- `[[#Heading]]` in the same note shows as missing.
- A `description` shows raw markdown (use `plainText`).
- The `plainText` comment rule eats text between `<!--` and `-->` inside code.
- FTS indexes the marker, so a search for "bookmark" matches every card; strip comments from the indexed body.
- Enter on a selected card opens its note: decide Mod-Enter to open and Enter for a new paragraph.
- Every card's options button has the same name: use "Options for <title>".
- `linkSwitchAt`'s rule belongs in the domain.
- ADR renumbered to 0020, since Phase 24 took 0019.
