Failing tests on branch `worktree-agent-a30ef8d1e387b0575` (commit 056c206, Phase 27 already merged with main there); review findings from the code-reviewer pass.

**Principle:** the webview, the model's output and every note's text are untrusted. The host enforces the lockdown in ADR-0021 and decides nothing else (ADR-0005).

**High:**

- **Spawn lockdown:** the host requires the _whole_ fixed argument shape (`--tools ""`, `--setting-sources ""`, `--strict-mcp-config`, `--no-session-persistence`, stream-json) and refuses any other set of flags.
- **Secrets as POST:** `model_http_post` is pinned in Rust to `https://api.anthropic.com/v1/messages` and the `anthropic` secret. No other secret can carry a POST.
- **Which `claude` runs:** only from Rust-owned install locations (not chosen by the webview), no path separators; the child gets a minimal environment.

**Medium:**

- **One write per Accept:** a proposal is marked accepting before the write, and both buttons are disabled.
- **New chat mid-turn:** it keeps nothing of the old turn (turn generation, dropped when stale); a vault switch too.
- **New notes into `.atlas`:** `propose_note` works out its final folder (incl. `atlas:` kinds), runs `chatWriteRefusal` on the full path, and the card shows it. Proposals into `Chats/` are refused.
- **Cards show where:** every card shows the vault path Accept writes.
- **Chat notes read back exactly:** tool lines are quoted so no text can start a new turn.
- **Title fence:** titles and paths in the context can't close the `<vault_data>` fence.
- **Timeouts:** `claude auth status` and runs time out.

**Low:**

- **Code fences:** a tool call inside a code fence isn't run; `</atlas_tool>` inside JSON is escaped by the prompt's rules.
- **Accept writes what the card showed:** the card previews the text as it will be written.
- **Cancel:** reaches every live run with that id.
- **Long lines:** over-long lines are cut, not split.
- **Retry:** it doesn't duplicate the question in the note.
- **Transcript size:** it is trimmed, keeping the last tool results in full and summarising older ones.
