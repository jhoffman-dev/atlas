Failing tests on branch `worktree-agent-a21dddde9aeac377d` (commit d9bef73); review findings from the code-reviewer pass.

**Leaks (high):**

- **Paths:** `messageWithoutPaths` misses paths wrapped in quotes (curly too), backticks, brackets or braces, after a comma, `~/…`, folder names with spaces, and UNC paths. It is also used by API answers and rule logs.
- **Chat questions:** a failed chat turn records the provider's raw text, which can quote the question. Record a fixed message plus the error's kind only.
- **Secrets:** redaction misses key names with spaces, `Cookie:`, lower-case hex tokens, keys containing `/`, `Bearer:`, and whole JSON string values.

**Accuracy (medium):**

- **Wrong vault:** index rebuilds and source refreshes that finish after a vault switch land in the new vault's log. Events carry the vault they're about, set where they happen.
- **False errors:** expected, recovered write failures are logged as errors (staged upload folders, create-note name retries, the daily-note race, image-name probes). Decided: record failures where a use case gives up, not at the write port; the probes are never recorded.
- **Link offers:** "update links?" after a rename is not an error. It isn't recorded; the stranded-edits notice is a warning.
- **One line per failure:** a red notice whose failure is already recorded by its source isn't recorded again.

**Cost and robustness:**

- **Bursts:** repeat checking is O(n²); use a map keyed by kind and message.
- **Re-reads:** every flush re-reads the whole file; hand listeners the new events instead.
- **Listener errors:** a throwing listener causes an unhandled rejection.
- **Main thread:** the Rust log commands run on the main thread; make them async.
- **Closing:** lines from the last 300 ms before closing are lost; flush on close.

**Clock:**

- **The badge:** it doesn't come back for a line dated ahead of the clock.
- **Repeats:** they use the absolute time difference.
- **A clock that jumps forward** never empties the log. Age is measured against the newest line, not only the clock.
