Left out of Phase 12 deliberately. A source is a public URL or a local file for
now — there is nowhere safe to put a token yet.

Needs a keychain binding on the Rust side (`keyring` or Tauri Stronghold) and
the entitlements to go with it, and `ATTACH`-ing a foreign SQLite file means
deciding what read-only means when the file is someone else's.

**Done 2026-09-26.** Secrets live in the login Keychain (`keyring-core` +
`apple-native-keyring-store`), named by a source as `{{secret:name}}` or
`auth: { secret: name }` and filled in by the host, which never returns a
value. `format: sqlite` reads someone else's database `mode=ro&immutable=1`
behind the Query page's guard, and refuses a pending WAL, a hot journal or a
file that changes mid-read; outside the vault only a file picked on this Mac
opens. Settings → Secrets lists names and the sources using them. Decisions in
ADR-0017.
