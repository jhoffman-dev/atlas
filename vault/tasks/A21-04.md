**Principle:** one wiki-link grammar, in the domain, read the same by the editor's tokenizer, the index (`linksIn`), rename (`retargetLinks`), plain text and tags (ADR-0018). Escapes (`\[[x]]`, `\|` in a table alias), line breaks and code spans behave identically everywhere.

**New in A21-03:**

- **Callout titles:** a title holding a link loses part of itself, and body edits rewrite the title line.
- **Table aliases:** `[[x\|y]]` in a table is read as a link to `x\` by the index and rename.
- **Escaped and split links:** they're text in the editor, but still links to the index.
- **`<br>` headings:** read as a break in h1/h2 too; it should be h3–h6 only, or also written as `<br>`.
- **Spaces around `<br>`** are lost.
- **Code spans:** one opening inside a link loses to the link. Decide deliberately, with a test.
- **`- - -` separators** are taken for a list when choosing markers.
- **Plain text** puts spaces around every link (`[[x]]#tag` becomes `[[x]] #tag`).

**Already on main (they change files):**

- **BOM notes:** an untouched block loses bytes when a neighbour is edited.
- **`&nbsp;` spacers:** an untouched spacer paragraph is deleted.
- **CRLF callouts:** read as plain quotes.
- **Tables:** a row with an unescaped `[[x|y]]` gains a column on edit.
- **Rarer cases:**
  - code ending `\|` in a cell splits it
  - bold `x<` before code `a@b.co>` becomes an autolink
- **Re-edit seeds:** 9 of 10,000 seeds (addresses reopened, then written as `<…>`, mostly in cells).

**Done:**

- One grammar: `WikiLinkReader` and `wikiLinkSpans` in the domain. The editor's tokenizer, `linksIn`, `retargetLinks`, `plainText` and the tag shields all read links through it. A code span that crosses a link's edge wins; one wholly inside a link is part of its name. A property test checks that the index, the parser and a rename agree across 1,500 generated notes.
- Callout titles are the first line as written. CRLF callouts are read as callouts, BOM offsets are fixed, and `&nbsp;` spacers are kept.
- Tables: a row with more cells than its header is kept as source. Code with an odd run of backslashes before a `|` gains one backslash, because GFM has no other way to write it. Links are written `[text](url)`, never `<url>`, and `<` is escaped before any character an email name can hold. The 9 re-edit seeds now read back.
- `<br>` is written in headings of every level, and the spaces beside it are kept. `- - -` is no longer taken for a list, and search text no longer puts spaces around links.
