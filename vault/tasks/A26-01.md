Failing tests on branch `worktree-agent-a5c08f12638f3a35d` (commit da79434, over the integrated branch `worktree-agent-a62187250b5daec32`); review findings from the code-reviewer pass.

**Decided — untouched text wins (ADR-0003 over ADR-0022's "the first keeps it"):**

- **Duplicate ids from the file:** never removed. Only ids duplicated inside the session (paste, split) get a fresh id.
- **The picker:** when a block's id isn't unique in its note, the picker gives that block a new id (via `anchorBlock`), so the link always opens the block that was picked.
- **Record it:** write this into ADR-0022.

**High:**

- **Changing a block's kind:** an id must follow its block when it becomes a bullet, task, quote, or heading. Obsidian allows `## Heading ^id`; write it there too, or, if a kind truly can't hold one, keep the id where it can be read and never drop it silently.
- **Duplicate ids:** see "decided" above.

**Medium:** keeping ids with their words costs ids × nodes per keystroke (look only at the changed ranges).

**Low:**

- **CRLF:** notes get no `blocks` rows (trim `\r`).
- **`- [ ]` items:** the first item of a list whose first line is only `- [ ]` gets more than the id's bytes rewritten.
- **Trailing spaces:** spaces before an id are lost on edit.
- **Embed redraws:** each embed redraws on every index revision (compare before `setContent`).
- **Non-note embeds:** `![[Paper.pdf#page=3]]` became a block embed; only note targets embed.
- **Visible ids:** the hidden ` ^id` has no on-screen marker (show a faint id).
- **One predicate:** the UI restates the "alone in a top-level paragraph" rule; share one domain predicate.
- **Picker reads:** the picker re-reads the target note on each keystroke (cache per note version).

**Done (2026-09-27):** every finding above, each with a failing test first; ADR-0022 amended.

- Ids follow their block into and out of lists, tasks, quotes and headings (`isAnchorPlace`, one rule). `## Heading ^id` and `- [ ] ^id` are read and written as Obsidian writes them. An id with no place left is written as words, never dropped.
- Duplicate ids from the file are left as they are, a note re-read from disk included; a change only takes an id off a block it gave it to. The picker withholds a shared id, so `anchorBlock` names the picked block, and reads a note once per version.
- Only what a change touched is looked at: the 300-id keystroke walks 1,200 nodes (was 182,700). CRLF, `- [ ]`, spaces before an id, embed redraws and `![[Paper.pdf#page=3]]` fixed; one `shownBlockLink` rule; a faint `^id` marker in both themes.
