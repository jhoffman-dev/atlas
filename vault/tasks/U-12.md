James, 2026-09-25: "Also, I want to be able to embed images into documents."

Done: paste (screenshots and files), drop onto the note, `/image` and "Insert
image…" in the page menu all copy the image into the vault and write a
standard `![alt](relative%20path.png)`. Settings → Images chooses the
`attachments/` folder (default) or beside the note. PNG, JPEG, GIF, WebP, SVG
and HEIC (when WebKit can draw it), up to 20 MB. Deleting an image removes
only the markdown; the file stays in the vault. No resizing, and no rendering
of Obsidian's `![[image.png]]` embeds yet — both left for later.
