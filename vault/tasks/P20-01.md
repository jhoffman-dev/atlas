Pure parser + exhaustive tests. `#` followed directly by text = tag; `# ` = heading. Multi-word closes on the next `#` on the same line (Bear). Case-insensitive identity, display keeps first spelling. Note: Obsidian reads `#tag me#` as tag `#tag` + text. U-19.
