Failing tests on branch `worktree-agent-ac4c1538a91f48cb9` (commit 5bbd636, with a real-git two-Mac harness); review findings from the code-reviewer pass; and the additions James asked for on U-29 (repo picker, auto commit+push while working, frequent pulls).

**Invariant:** no version of any file is ever lost, and no conflict markers are ever left in any file. Every divergent version survives somewhere visible, and each conflict is noted in the Activity log.

**High:**

- **Only vaults Atlas set up sync.** A vault counts as set up only with Atlas's marker (the managed `.gitignore` block plus a sync entry in `.atlas/settings.md`). Any other repo is `not-set-up` and is offered "connect".
- **Crash-safe settling.** A journal (in `.git/atlas-sync/`) records each hold, copy and checkout step, and the next sync finishes or rolls back from it first. `setUp` runs through the same one-at-a-time runner as every sync.
- **Case collisions.** Before merging, compare the remote's paths with ours by case-folding (and NFC) in the domain. A colliding local file goes to a conflict copy first. Case-only renames reach the other Mac.
- **Unreadable or huge conflicted files.** Take our and their versions from the git index (stages 2 and 3) as bytes, never by reading the file as text, so no markers are left in non-UTF-8 or large files.

**Medium:**

- **Default branch.** Connecting a repo checks out its default branch (no `main`/`master` split).
- **Large files.** Files over GitHub's limit (≈95 MB and up) are never committed; they're listed as not synced, with a warning. Recover a vault whose unpushed history already holds one.
- **Typing below markers.** Typing below leftover markers is kept: only a file whose bytes still equal git's markered merge is replaced.
- **Global git settings.** Neutralize them with `-c merge.ff=true -c core.autocrlf=false -c commit.gpgSign=false -c core.excludesFile=` (and similar) in the host's fixed prefix. `gh repo create` runs without hooks.
- **Nested repos.** A sub-folder that is its own repo is left out of sync, with a warning, instead of becoming a gitlink or breaking `add`.
- **Backslashes.** Conflicts on names containing `\` can be settled.

**Low:**

- **Tokens in addresses.** Addresses that carry a login or token are refused.
- **Symlinked vaults.** A vault opened through a symlink resolves correctly.
- **Branch names.** Any branch name git allows is accepted (check with git's own rules).
- **`index.lock`.** It's removed only after a local run times out, and only if it's older than that run.
- **Automations Mac.** Pick it by a stable per-Mac id kept in app data, not by name, and don't run scheduled rules until settings load. A Mac that connects doesn't take over automations.

**James's additions:**

- **Repo picker.** Settings → Sync lists his GitHub repos (a read-only `gh repo list` host shape), with search, plus "create a new private repository" and "paste an address". Connecting asks the host to confirm first.
- **Push while working.** Commit and push about 30 s after typing stops or any change, and at most every 5 min of continuous editing.
- **Frequent pulls.** Fetch every minute and merge when the remote moved. Open notes reload, and unsaved typing is never overwritten.
- **Settings.** Adjustable intervals, a pause switch, and a sidebar light for synced, syncing, behind and error.
