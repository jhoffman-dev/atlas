James, 2026-09-27:

We need a proper tags feature. This is a bigger one that may need to be broken up into smaller steps.

- When I type # and immediately followed by text, no space to differentiate it from a markdown header, it then either creates a new one or suggests from a list of tags.
- Multi-word tags start and end with a # like bear notes handles it. Example: #tag me#
- Multii-level tags are auto managed with the slash. Example: #para/resource
- A view to manage, the list and change them should be available. The view should have:
  - sort by name or frequency
  - Ability to change the tag name and have it propagate everywhere
  - Next to the tag should be a number with the number of instances
  - If a tag is clicked on, it should show a list of notes that have it
- A tag should be auto removed from the list if all instances have been deleted
