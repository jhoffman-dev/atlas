Failing tests on branch `worktree-agent-abe2d9e1c69478a63` (commit 8612611); review findings from the code-reviewer pass.

**Principle:** a rule file and its log are text anyone could have written or synced (like a source note). Undo only reverses what _that_ rule was allowed to do and actually did.

**High:**

- **Undo trusts log lines.** Undo accepts any key or note a log line names. Check every line against the rule's own action and `setKeyProblem`, and the value's shape. Unarchive only a note whose archive stamp is from the run being undone. Skip and report the rest.
- **Unlogged changes.** A run cut off mid-way (vault switch, failed log write) leaves changes nothing records. Log what was done even when the run stops (`finally`). If the log itself can't be written, pause the rule and say so rather than retry every minute.
- **The cap stalls.** Already-done notes take the 500 slots, so a `set` rule over 500 never finishes, nor archive with `INCLUDE ARCHIVED`. Leave no-ops out _before_ capping.

**Medium:**

- **Rules that never run.** A rule that has never run, whose time falls while Atlas is closed, never runs. Write a first mark when a rule is first seen or turned on.
- **`enabled`:** `yes`, `"true"` or `1` read as a silent "off". Show the rule as broken with "write enabled: true or false".
- **Undo deletes empty keys.** A key that was present but empty (`status:`) is deleted, and logged as restored.

**Low / minor:**

- **Stable ids.** Give each rule a stable `id:` and name its log after it. A new rule with a deleted rule's name must not inherit that log, and renaming a rule must keep its history.
- **Future marks.** Marks later than now (a clock that ran fast, or a synced entry) are ignored, with a notice.
- **`__proto__`** as a set key is refused.
- **Same-second runs.** A run in the same second as an undone one stays undoable (order by entry, not time).
- **Leading zeros.** Values like `007` or `02134` stay text.
- **Log size.** Cap the log by bytes too, and keep sections that don't parse.
- **"Stopped at N"** counts notes, not key changes.
- **Re-reads.** Rules and logs aren't re-read on every note save.
- **Type check.** `status = @today` is checked like the query page does, before pinning.
- **Dropped saves.** An editor save during a busy run isn't silently dropped.
