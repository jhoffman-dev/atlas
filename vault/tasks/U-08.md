James, 2026-09-23: "Another interesting feature to add would be a way to save and organize claude artifacts in the tool"

Planned as P17-07, after wave 2. Proposed shape, to confirm with James before building:

- An **Artifact** type: a note per artifact with `url` (the claude.ai link), `kind` (page, deck, design, doc), `project` relation, tags, and a saved copy of the page (the HTML and its files) in the vault, so it still opens offline and can be searched.
- **Save**: paste a claude.ai artifact link, drop an `.html` file, or have Claude save one through the MCP server (`atlas_save_artifact`), so an artifact made in a Claude session lands in Atlas with one call.
- **View**: the saved page renders in a sandboxed frame inside Atlas (scripts isolated from the app and the vault); a gallery view of artifacts with thumbnails, filterable by project and kind.
- Open questions: whether to keep the live link only, a saved copy only, or both (default: both); how thumbnails are made.

James, 2026-09-25, on the proposed shape: "yes". Building as P17-07 with both the link and a saved copy.
